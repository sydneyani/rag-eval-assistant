# CiteGround open corpus

These documents are **synthetic**. They follow the shape of a U.S. Form 10-K and a shareholder letter so the assistant has a public-filing-style corpus with stable facts, but Helios Systems, Inc. is not a real issuer. Nothing here is an SEC filing, and nothing here is investment advice.

The loader skips this file. Evaluation labels in `data/eval/qa.jsonl` point at section ids inside the other documents.

Facts are internally consistent on purpose. If you edit a number, update the labeled QA set in the same change.
